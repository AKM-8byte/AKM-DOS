# AKM Horizon startup sound

`akm_horizon.wav`: original 3.6-second AKM-DOS cue created for this project
on 2026-10-07. Complete reproducible source: `tools/generate_startup_sound.py`.
Two synthesized BIOS-like pulses precede a warm rising C-major chord.
No recordings, samples, third-party melodies or Windows audio were used.
Format: mono, PCM 16-bit, 44,100 Hz.
Regenerate: `python tools/generate_startup_sound.py`.
